# college-service-robot
Autonomous indoor service robot under development using ROS 2 and NVIDIA Isaac Sim for simulation, perception, and navigation.


Status:  Under Development

# Overview

The Autonomous Campus Delivery Robot is a mobile robotics platform designed to automate short-distance delivery tasks inside educational and institutional environments.

The system is being developed with a focus on autonomous navigation, perception, localization, obstacle avoidance, and delivery-task execution.

The robot is intended to operate within environments such as:

College buildings
Academic blocks
Laboratories
Hostels
Offices
Indoor corridors

The current development phase focuses on building and validating the robot in ROS 2 and Gazebo simulation before transitioning toward physical hardware implementation.

 # Objectives

The primary objectives of the project are:

Develop a mobile robot capable of autonomous indoor navigation.
Build a realistic simulation environment representing a college campus/building.
Implement robot localization and mapping.
Enable autonomous path planning and obstacle avoidance.
Integrate LiDAR and RGB-D/depth perception.
Develop a modular ROS 2 software architecture.
Validate navigation and robot behavior in Gazebo before hardware deployment.
Create a platform that can later be extended for autonomous delivery applications.
